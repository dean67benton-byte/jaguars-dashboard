# Jaguars Hub

- Preact + Vite + TypeScript PWA, hash routes, deployed to GitHub Pages by `.github/workflows/update-data.yml`.
- Data files `public/data/{football,mbb}.json` are generated by `scripts/fetch-data.mjs`; don't hand-edit except seeds.
- Briefs live in `public/briefs/`; the scheduled routine follows `docs/BRIEF_ROUTINE.md`.
- Owner preferences: iPhone, dark mode, South Alabama navy and red, no betting lines in phase 1, football briefs only unless enabled.
- Run `npm run build` before committing.
